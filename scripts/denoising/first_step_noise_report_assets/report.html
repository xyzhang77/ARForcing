02 · 跨 seed 的分散程度

现在能不能说明 diversity？

能描述这 24 个配对样本中的差异，尚不能证明总体的语义 diversity 排序。以下将可计算的 RGB 分散程度与视觉上的语义变化分别呈现。

定量：跨 seed 低通 RGB MSE

AR 距离 ÷ Wan 距离，越小表示 AR 在这个指标下越集中。

比值 < 1：AR 的 RGB 更集中比值 > 1：AR 的 RGB 更分散探索性 95% 区间 含 1：方向仍不确定
PromptAR MSEWan MSEAR / Wan · 探索性 95% 区间当前指标下的判断

每个 prompt 8 个 seed、28 个不同 seed 对。以 8 个 seed 为单位有放回重采样，对原始身份不同的 pair（distinct-identity pair）按抽样次数乘积加权；重复抽中的同一身份不计为新 pair。探索性 95% 区间没有对 prompt 重采样，也未作多重比较校正，不代表跨 prompt 的泛化。三个观察帧共同降采样到 15 × 26 RGB 后计算，颜色、亮度和布局都会影响数值。

视觉：场景类别与构图偏好

这些观察来自同一批样本，尚未经过盲评或语义特征的独立验证。RGB 距离接近，也可能同时存在场景类别或镜头尺度的差异。

猫的画面看起来更多样，为什么 MSE 仍然接近？

低通 RGB MSE 将所有像素差异压成一个平均数。相似构图里的颜色或亮度变化可以增大它；不同场景中相近的背景颜色又可能缩小它。因此，“杯边近景”和“地面水源远景”这样的语义变化，不一定带来更大的平均 RGB 距离。当前只能把视觉观察当作待验证的线索。

要把 diversity 结论做实，还缺什么？

扩大 prompt 与 seed；对 final 计算感知 / 语义特征距离，并单独标注构图、场景类别、物体与动作变化；同时报告 prompt 一致性与画质，避免把偏题或低质量样本当作多样性。若要解释成因，再在权重、CFG、调度器和时域匹配的控制下比较。

03 · 单条轨迹的早期特征

结构保留：早期 x₀ 能否对应自己的 final？

把某个 seed 的早期 x₀，与同 prompt 下 8 个 final 分别计算低通 RGB 距离；最近的是自己的 final 就记为检索成功。它衡量轨迹内的可辨认性，不衡量模型覆盖了多少语义模式。

PromptAR 检索Wan 检索AR 配对 / 错配距离Wan 配对 / 错配距离

单个 prompt 的机会水平为 1 / 8 = 12.5%。检索成功与“以后不会再改变”不同：只要自己的 final 比其他 seed 更接近即可。这里观察的是首个 chunk 的帧 0 / 4 / 8，不能直接推广到完整视频的时序多样性。
