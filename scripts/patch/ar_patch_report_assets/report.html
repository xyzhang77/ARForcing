Latent 通道 RMS 与相对 baseline 的差异

RMS = √mean(channel²)，delta RMS = √mean((branch − baseline)²)，都不是解码图像。幅值图统一色标 0–4，差异图统一 0–1；超过上限会饱和。下一 chunk 的 step 0 可有完全相同的 noisy 输入，而预测因 AR 上下文不同而变化。

单一 prompt / seed 的完整扫描，不能外推为普遍 anchor 结论。每个 patch 含多个 transformer tokens，面积可能不同；请同时看原始与输入能量归一化响应。
